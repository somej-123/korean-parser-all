# DOCX 코퍼스 일괄 실행

웹에서 받은 공개 라이선스 DOCX를 한꺼번에 파싱·렌더링해서 실패, 경고, 처리 시간, 추출 요소 수를 집계한다.

```bash
./fetch_samples.sh samples_web        # Apache POI 테스트 문서 + OpenOffice 개조식 템플릿
python run.py samples_web --out corpus_report.md
```

## 결과 (2026-10-15)

| 항목 | 값 |
|---|---|
| 문서 | 131개 (Apache POI 130 + OpenOffice 1) |
| 성공 | 115개 (정상 문서 전부) |
| 실패 | 16개, 모두 의도적으로 손상·암호화된 테스트 파일 (퍼저 생성 파일, 잘린 파일, 암호 걸린 문서) → `DocumentError`로 이유 안내 |
| 처리 시간 (파싱+HTML+LLM) | 중앙값 4ms, 최대 4.2초 (표 셀 11,505개짜리 문서) |
