## 나라장터 첨부파일로 시험하기

실제 공공 문서(제안요청서·과업지시서)는 HWP·HWPX·PDF가 섞여 있어 좋은 시험 자료다.
나라장터 웹사이트는 로그인을 거치므로, 공공데이터포털 API로 첨부파일 주소를 받는다.

```bash
# https://www.data.go.kr 에서 '조달청_나라장터 입찰공고정보서비스' 활용신청 → 일반 인증키 발급
export G2B_SERVICE_KEY='발급받은 키'
python fetch_g2b.py --days 7 --limit 30 --out samples_g2b
python run.py samples_g2b --pdf --out g2b_report.md
```

받은 파일은 저장소에 올리지 않는다. 공고 문서의 재배포 조건은 공고마다 다를 수 있다.
(이 스크립트는 API 명세 기준으로 작성했고, 서비스 키가 없어 아직 실제 호출로 검증하지 못했다.)

## 실제 제안요청서 7종 (2026-10-16)

나라장터 공고 첨부 PDF, 공공기관 누리집에 올라온 제안요청서·평가지침 PDF, 과기정통부·NIPA의
「공공SW사업 제안요청서 작성 예시」(HWPX, 공공누리 제1유형)와 그 DOCX 변환본으로 시험했다.

| 항목 | 값 |
|---|---|
| 문서 | 7개 (HWPX 2, DOCX 1, PDF 4: 21~46쪽) |
| 성공 | 7개 전부 |
| 처리 시간 | 중앙값 15초, 최대 93초 (46쪽 PDF, CPU) |
| 추출 | 문단 6,539 · 제목 238 · 표 261 (병합 셀 있는 표 119) · 도식 85 · 그림 52 |

이 시험에서 찾아 고친 것:

- PDF 고정 배치: 글자 폭 정보가 깨진 글꼴(모든 글자 상자가 글자 크기만큼)에서 `(20)`이 `@)`처럼,
  `5.0`이 `50`처럼 보이던 문제 → 글자 간격을 잉크 상자가 아닌 글자 기준점으로 잰다
- PDF 고정 배치: 장평을 줄인 표 안 글에서 띄어쓰기가 사라지던 문제 → 이웃 글자의 보통 간격과 비교해 단어 사이를 찾는다
- PDF 고정 배치: 글머리 기호(□)가 사용자 정의 영역 문자라 빠지던 문제 → 그 글자 개체는 바탕 그림에 남긴다
- PDF 고정 배치: 검은 상자 위 흰 장 번호가 사라지던 문제 → 잘라내기 경로로 일부만 보이는 그라데이션 조각을 '덮개'로 오판하지 않는다
- PDF: 한글이 PDF에 넣는 HY 글꼴 이름(H2hdrM = HY헤드라인M 등)을 굵은 글꼴로 인식
- HWPX: 한글이 자동으로 넣는 그림 설명('그림입니다. 원본 그림의 이름: …')을 파일 이름만 남김
- LLM 텍스트: 칸 대부분이 빈 표지 배치용 표는 표가 아닌 글로 풀어 씀

PDF 원본과 그 비교 그림은 재배포 조건이 문서마다 달라 저장소에 넣지 않았다. HWPX 작성 예시는
`tests/fixtures/hwpx/rfp_example.hwpx`로 넣고 회귀 시험에 쓴다.
