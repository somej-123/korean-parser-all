# v1.0 완료 기준 (파서의 최종 목표)

2026-10-17 사용자와 정했다. 이 문서의 기준을 모두 만족하면 파서 v1.0이다.
**2026-10-18 모두 통과해서 v1.0.0으로 확정했다** (기준 1: 파일 341개, 예외 1개 / 기준 2: 지표 11개 / 기준 3: 요소 113개 /
기준 4: 시험 249개).
새로 생각난 일은 바로 하지 않고, 이 기준에 들어가는지 먼저 본다. 들어가지 않으면 'v1.0 이후'에 적는다.

실행 환경 (2026-10-18 사용자와 정함): **GPU가 없는 환경에서 CPU만으로 가볍게 돌면서 좋은 결과를 내는 것**이 목표다.
기본값은 CPU이고 GPU 설정은 넣지 않는다 (CUDA판 PyTorch를 요구하지 않는다).
우선순위 (2026-10-18 사용자와 정함): **품질이 먼저다.** 시간이 더 걸려도 품질이 좋아지는 쪽을 고른다. 속도는 품질이 같은
방법끼리 고를 때만 본다 (예: 텍스트 레이어 PDF는 표 구조 모델을 끄고 괘선으로 표를 읽은 뒤, 읽지 못한 쪽만 모델을 다시
돌린다. 품질이 같고 더 빠르다).

## 기준

### 기준 1. 빠짐없이

- **기준 문서 묶음**(아래)의 모든 파일에서 원문 글자 보존율이 0.99 이상이다 (텍스트 레이어가 있는 PDF, DOCX, HWPX, HWP, PPTX, XLSX).
  원문 글자는 파서와 따로 읽는다: PDF 텍스트 레이어, DOCX `w:t`, HWPX `hp:t`, HWP 문단 글 레코드, PPTX `a:t`, XLSX 칸 값.
  일부러 버리는 것(PPTX 쪽 번호, 되풀이되는 머리말·꼬리말의 두 번째부터)과 경고만 남기는 것(HWP 문단 아래 달린 글 목록)은
  빼고 잰다. 메모(HWPX·Word·XLSX·PPTX)는 v1.4.0부터, 바탕쪽·숨은 설명은 v1.4.1부터 읽으므로 원문에 넣는다.
- 못 읽은 개체는 모두 `warnings`로 알린다. 경고 없이 사라지는 글은 0건이다.
- 예외 (2026-10-18 사용자와 정함): 파서가 일부러 둔 크기 제한에 걸려 그 사실을 경고로 남긴 파일은 보존율이 0.99 미만이어도
  미달로 보지 않는다. 지금 기본으로 걸린 제한은 없다 (XLSX 칸 수 상한은 v1.4.0에서 없앴고, KP_XLSX_MAX_CELLS를 정했을 때만 걸린다).
  제한을 새로 두면 이 목록과 `benchmarks/goal/check.py`의 `LIMIT_WARNINGS`에 함께 적는다. 보고서에는 예외 파일도 따로 보인다.

### 기준 2. 구조 정확도

합성 정답 세트(`benchmarks/eval`)와 한컴 미리보기 비교로 잰다.

| 대상 | 기준 |
|---|---|
| PDF | 글자 오류율 1% 이하, 어절 F1 0.98 이상, 표 TEDS 0.95 이상, 제목 재현율 0.95 이상, 읽기 순서 0.99 이상 |
| 스캔 PDF | 어절 F1 0.94 이상, 표 TEDS 0.92 이상 (그림으로 만든 쪽에 보이는 부분 기준), 글자 오류율 2% 이하 (2026-10-17 올림: 처음 값 0.88·0.85·15%는 그림에 없는 쪽 글이 정답에 섞여 있던 평가로 정한 것이었다) |
| DOCX | 제목 재현율(추정 제목 포함) 0.95 이상, 표 TEDS 1.000 |
| HWPX | 한컴 미리보기 글자 재현율 평균 0.98 이상 |

### 기준 3. 필수 요소 (닫힌 목록)

원문에 있으면 여섯 형식 모두에서 읽는다. 이 목록 밖의 요소는 v1.0 목표가 아니다.

글, 제목·번호 계층, 표(병합 칸), 그림(대체 글), 각주·미주, 머리말·꼬리말, 하이퍼링크, 차트 데이터, 수식(원문 스크립트),
도식 안 글.

### 기준 4. 쓰는 쪽과의 약속

결정성(같은 파일 → 같은 결과), JSON 왕복, 문서 안에서 유일한 블록 id, IR 1.x 유지(이름·의미를 바꾸면 2.0),
손상·암호 파일 안내, 시험 전부 통과. 지금도 지키고 있으며 계속 지킨다 (`tests/test_contract.py`).

### 기준선 (2026-10-17, v0.14.0)

- 기준 1: 82개 중 3개 미달, 셋 다 경고 없음. HWPX 메모(`fieldBegin type="MEMO"`) 안의 글 3,071자를 읽지도 알리지도
  않았다 (같은 문서의 사본 포함 2개). HWPX 도형 캡션('그림')이 빠졌다 (1개).
- 기준 2: 11개 지표 중 10개 통과. 스캔 표 TEDS 0.820 (기준 0.85).
- 2번 뒤 (v0.14.1): 기준 1 통과 (82개 모두 0.99 이상, 경고 없이 빠진 글 0건). 개체 캡션을 읽고, 메모·바탕쪽 글은
  경고를 남긴다. 기준 문서 묶음의 바탕쪽에는 글이 없었고 연결된 글상자는 없었다.
- 3번 뒤: 스캔 정답에 그림에 없는 4쪽 글이 섞여 있던 평가 실수를 바로잡았다 (benchmarks/eval/README). 스캔 표 TEDS
  0.948, 글자 오류율 0.8%, 어절 F1 0.955로 기준 2 모두 통과. 스캔 기준값은 예전 정답으로 정한 것이라 F1 0.94·
  표 0.92·글자 오류율 2%로 올렸다 (지금 값보다 조금 낮게: 품질이 떨어지면 기준이 알려 준다).
- 4번 뒤 (v0.15.0): hwplib HWP 44개를 기준 문서 묶음에 넣었다 (126개). HWP 차트(OLE 안 VtChart)의 데이터 표를 읽는다.
  넣으면서 HWP 개체 캡션이 빠지던 것을 고치고, 바탕쪽·숨은 설명·문단 아래 달린 글 목록은 경고를 남긴다. 기준 1 통과 (126개).
- 5번 뒤 (v0.16.0): PDF 링크(실제 PDF 3개의 링크 모두)와 각주(시험 문서 `tests/fixtures/footnotes.pdf`)를 읽는다.
  위 첨자 각주 번호가 문단 맨 앞으로 가던 글 순서 오류도 고쳤다. 기준 1·2 모두 통과 (127개, 11개 지표).
- 6번 뒤 (v0.17.0): Apache POI의 chartex.docx 하나를 받아(사용자 허락) 신형 차트의 데이터를 읽는다 (상자 수염, 선버스트).
  DOCX·PPTX·XLSX가 같은 해석을 쓴다. 신형 차트가 든 PPTX·XLSX 실제 표본은 없다.
- 7번 뒤 (v0.18.0): 표본 문서 7개와 요소 목록으로 기준 3을 잰다. 표본에서 찾아 고친 것: Word 수식(OMML)이 빠짐,
  LibreOffice가 쓴 □ ○ 글머리표(MT Extra·Wingdings 2)가 깨짐, 한글의 짝수 쪽 머리말이 경고 없이 빠짐.
  **기준 1(135개 파일)·2(11개 지표)·3(요소 113개) 모두 통과.** 기준 4는 시험(241개)으로 지킨다.
- 공공데이터포털 문서 147개를 더한 뒤 (v0.19.0): 처음 재니 0.99 미만이 15개(경고 없음 14개)였다. 찾아 고친 것:
  DOCX VML 그림 묶음(v:group)의 둘째 글상자부터와 다른 구역의 머리말이 빠짐, PDF 그림 안 글(목록 묶음 아래 글, Docling이
  자식으로 넣지 않은 글)이 빠짐, 목록 항목의 ‘ ’가 '로 바뀜, 문단 첫 줄 위쪽 따옴표(’25년)가 빠짐, 폭이 깨진 글꼴의
  줄 끝 ')'가 빠짐, 장마다 바뀌는 PDF 머리말이 빠짐. 측정 쪽 잘못(쪽 번호만 다른 머리말을 따로 셈, 쪽 밖에 그려진 글자를
  셈)도 바로잡았다. 결과: **파일 264개 중 0.99 미만 1개, 경고 없이 빠진 파일 0개.** 남은 1개는 82만 칸짜리 XLSX 조사
  원자료로, 칸 수 제한(20만 칸)에 걸려 경고와 함께 앞부분만 넣었다. 이 파일은 기준 1의 예외로 정했다(2026-10-18)
  → **기준 1 통과 (예외 1개).** 기준 2(11개 지표)·3(요소 113개)은 그대로 통과.
  (v1.4.0에서 XLSX 칸 수 상한을 없애 이 파일도 보존율 1.000이 되었다. 칸 메모·글상자·머리글 글도 원문으로 센다.)
- 처음 보는 공공데이터포털 문서 77개(`samples_rfp/datagokr_new`)를 더한 뒤 (v0.20.0): 고치지 않고 다른 파서와 비교한 뒤
  (`benchmarks/compare/README.md`), 드러난 두 문제를 고쳤다. 확장자만 `.hwpx`인 PDF 3개를 '손상된 파일'로 거절함 → 형식을
  내용으로 정하고 경고. 글자를 곡선으로 바꾼 사본이 겹쳐 그려진 ❶이 가려진 글로 버려짐(0.966) → 같은 자리·같은 색의
  도형은 덮개로 보지 않음(0.997). **파일 341개 모두 통과 (예외 1개)**, 기준 2·3 그대로 통과. 시험 249개.

## v1.0 목표에 넣지 않는 것

- 원본과 똑같은 화면: 그림자, 그림 자르기, 장평, 세로쓰기, 다단 화면 배치, 일부 preset 도형

- 조건부 서식
- 분류·임베딩·검색·정보 추출·요약·AI 그림 설명 (후속 프로젝트, `SCOPE.md`)
